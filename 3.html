Puzzle 3: Mr. Green Likes

Type one word to see whether Mr. Green likes it. Try to figure out the hidden rule.

Rule Explanation

Mr. Green likes words that contain at least one pair of double letters.

The word must be a single word using letters only. If the word has two of the same letter in a row, Mr. Green likes it. If it does not, he does not like it.
